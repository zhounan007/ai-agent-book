# pptx Skill 技术细则（第三层）

本文件仅在 Agent 已决定制作 PPTX 后加载，平时不占用上下文。

## 沟通与叙事

- 先明确受众应理解什么，再安排页序。
- 每页只表达一个主要结论。
- 标题应是可以直接说出口的判断，不使用泛化章节名。
- 结尾要回扣开场问题，不使用空泛的“谢谢”页。

## 视觉系统

- 使用 Codex Grid：白色画布、黑色主文字、浅灰结构区、蓝色单一强调。
- 画布为 `LAYOUT_WIDE`（13.333 × 7.5 英寸）。
- 标题页主标题至少 50pt；内容页标题至少 35pt；正文至少 16pt。
- 相邻页面应改变轮廓，避免连续重复相同的卡片网格。
- 内容过多时删减或拆页，不通过缩小字号强塞。

## PptxGenJS

- 使用公开 npm 依赖 `pptxgenjs` 生成可编辑的 Office Open XML PPTX。
- 所有元素坐标必须通过静态越界和重叠检查。
- 每页都写入 `[Sources]` speaker notes，注明来源 Markdown。
- 使用 LibreOffice 转 PDF，再用 Poppler 导出逐页 PNG。
- 输出 PPTX、PDF、布局报告、逐页 PNG 和全套 montage。

## 验收

1. 总页数 8–12 页。
2. 每页标题不换行、不溢出。
3. 没有无意重叠、裁切或超出画布。
4. 最终 PPTX 可以重新渲染。
5. 逐页人工查看，并运行溢出检测脚本。
