# 我的 AI Agent 学习区

这里存放个人学习路线、进度和实验记录，与原书及配套代码分开。

## 学习目标

- 以实践理解 AI Agent 的核心概念。
- 围绕“模型 + 上下文 + 工具”建立完整知识框架。
- 精选代表实验，不以跑完全部项目为目标。
- 每个阶段都产出可解释、可复现、可验证的结果。

## 文件说明

- [ROADMAP.md](ROADMAP.md)：按里程碑组织的个性化学习路线。
- [PROGRESS.md](PROGRESS.md)：整体进度与阶段验收记录。
- [experiments/TEMPLATE.md](experiments/TEMPLATE.md)：单个实验的记录模板。

## 学习方式

每次学习只完成一个小闭环：

1. 写下本次要回答的问题。
2. 阅读对应章节的必要部分。
3. 先跑离线或最小路径。
4. 修改一个关键变量并做对比。
5. 用自己的话解释结果。
6. 按模板保存实验记录并更新进度。

不按天数安排进度。时间少时完成阅读、代码走读或离线自检；时间充足时运行在线对照实验。

## 基本约定

- API Key 只放在本地环境变量或项目的 `.env` 中，不写入学习记录或提交到 Git。
- 安装依赖前先阅读对应项目的 `README.md`，尽量为每个实验使用独立虚拟环境。
- 在线实验先缩小样本数，确认流程正确后再扩大，避免不必要的 API 成本。
- 实验失败也要记录：失败原因和排查证据本身就是学习成果。
